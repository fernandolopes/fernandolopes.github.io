Kisaude

Política de Privacidade

1. Apresentação

O Kisaude é um aplicativo de saúde desenvolvido para ajudar os usuários a gerenciar e acompanhar informações relacionadas ao seu bem-estar. Esta Política de Privacidade descreve como coletamos, utilizamos e protegemos os dados dos nossos usuários.

Ao utilizar o aplicativo, você concorda com as práticas descritas neste documento.

Data de vigência: 19 de abril de 2026.

2. Dados Coletados

Para o funcionamento adequado do aplicativo, podemos coletar as seguintes informações:

  • Informações de perfil fornecidas pelo usuário (nome, e-mail);
  • Dados de saúde inseridos voluntariamente no aplicativo;
  • Informações de uso do aplicativo (telas acessadas, frequência de uso, erros e falhas);
  • Dados técnicos do dispositivo (versão do sistema operacional, modelo do dispositivo).

3. Finalidade do Uso dos Dados

Os dados coletados são utilizados exclusivamente para as seguintes finalidades:

  • Funcionamento do aplicativo de saúde: os dados de saúde fornecidos são usados para oferecer as funcionalidades do Kisaude, como acompanhamento de indicadores, histórico e recomendações personalizadas;
  • Análise e melhoria do aplicativo: informações de uso e dados técnicos são analisados para identificar problemas, corrigir erros e aprimorar a experiência do usuário.

Compromisso: afirmamos que não compartilhamos, vendemos ou repassamos os seus dados a terceiros para nenhuma finalidade, seja comercial ou de outra natureza.

4. Não Compartilhamento com Terceiros

Os dados coletados pelo Kisaude são de uso estritamente interno. Não realizamos, sob nenhuma circunstância, o compartilhamento, venda, troca ou cessão de dados pessoais ou de saúde dos nossos usuários com terceiros.

Excepcionalmente, poderemos divulgar informações apenas quando:

  • Exigido por determinação legal ou ordem judicial;
  • Necessário para proteger os direitos e a segurança dos usuários do aplicativo.

Mesmo nessas situações, divulgaremos apenas as informações estritamente necessárias.

5. Armazenamento e Segurança

Adotamos medidas técnicas e organizacionais adequadas para proteger os seus dados contra acesso não autorizado, perda, alteração ou divulgação indevida.

Os dados são armazenados de forma segura e acessíveis apenas pelas equipes responsáveis pelo desenvolvimento e manutenção do aplicativo.

6. Direitos do Usuário

Em conformidade com a Lei Geral de Proteção de Dados (LGPD — Lei nº 13.709/2018), você tem os seguintes direitos sobre seus dados:

  • Acessar os dados que temos sobre você;
  • Solicitar a correção de dados incorretos;
  • Solicitar a exclusão dos seus dados pessoais;
  • Revogar o consentimento para uso dos dados a qualquer momento.

Para exercer qualquer um desses direitos, acesse nossa página de exclusão de dados ou entre em contato pelo e-mail abaixo.

7. Alterações desta Política

Esta política poderá ser atualizada periodicamente para refletir melhorias no aplicativo ou mudanças legais. Quando houver alterações relevantes, a data de vigência no início deste documento será atualizada.

O uso continuado do aplicativo após a publicação de alterações constitui aceitação da política revisada.
